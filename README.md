# Образование Японии

Create a complete Russian-language educational website about the JAPANESE EDUCATION SYSTEM.

The website should use the visual style of Web Japan (web-japan.org) as inspiration: clean editorial design, white backgrounds, Japanese red accents, high-quality photography, structured information sections, subtle borders, strong typography, and generous whitespace.

IMPORTANT:

This website is NOT a general website about Japan.

The entire content should focus on:

"Система образования Японии"

The goal is to help Russian-speaking students understand how education works in Japan, from kindergarten through university.

Do not make it feel like a PowerPoint presentation. It should feel like a real educational information portal that users can scroll through and explore.
